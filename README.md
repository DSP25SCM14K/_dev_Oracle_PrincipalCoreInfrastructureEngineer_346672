# Dev Kumar — Distributed Systems & Application Security Portfolio

A responsive engineering portfolio featuring an animated edge policy topology, application security story, full experience history, and project links.

Open `index.html` directly or serve this folder with a static web server. GitHub Pages publishes the repository root with the included Actions workflow.

- `index.html` — portfolio content and WAF policy flow diagram
- `styles.css` — responsive design and animation
- `script.js` — animated edge topology background, rotating focus text, reveals, and project search
